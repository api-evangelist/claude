# Claude

Claude is Anthropic's family of large language models and the assistant built on them. It is a product, not a separate API provider: the Claude API (Messages, Message Batches, Models, Files, Admin and Usage/Cost) is profiled in the anthropic repository, which is canonical. Consolidated 2026-10-13, approved by Kin Lane.

Canonical profile: [api-evangelist/anthropic](https://github.com/api-evangelist/anthropic) — https://apis.io/providers/anthropic/
